# 📊 Actuarial Reserving Pilot

An actuarial analytics project focused on implementing and comparing classical non-life insurance loss reserving techniques. This repository serves as a pilot platform for reserve estimation, claims development analysis, and actuarial reporting.

## Overview

This project explores deterministic reserving methodologies widely used in the insurance industry to estimate outstanding claim liabilities from historical claims development data.

The objective is to provide transparent, reproducible actuarial calculations while offering clear visualizations and analytical insights.

---

## Features

- Claims triangle analysis
- Development factor calculation
- Ultimate loss estimation
- IBNR (Incurred But Not Reported) reserve estimation
- Reserve adequacy analysis
- Interactive visualizations
- Clean actuarial reporting

---

## Reserving Methods

- Chain Ladder
- Mack Method 
- Bornhuetter-Ferguson
- Development Factor Analysis
