# 📊 Loss Reserving Dashboard

An interactive web dashboard for actuarial loss reserving techniques, designed to visualize and compare traditional reserving methods used in non-life insurance.

## ✨ Features

- 📈 Chain Ladder Method
- 📉 London Chain Method
- 📊 Taylor Separation Method
- Interactive charts powered by Chart.js
- Responsive modern interface
- Dynamic reserving exhibits
- Clean actuarial reporting layout
- Browser-based (no installation required)

## 📚 Reserving Methods Included

### Chain Ladder

A classical actuarial technique that projects future claims development using historical development factors.

### London Chain

An extension of the Chain Ladder model that incorporates an intercept to improve reserve estimates when development patterns are not proportional.

### Taylor Separation

A reserving approach that separates claim inflation from claim frequency, allowing a more flexible estimation of outstanding liabilities.
